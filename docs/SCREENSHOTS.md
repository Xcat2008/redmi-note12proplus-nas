# Live captures / Capturas reais

The images in `docs/screenshots/` were captured from the running Homeio server on the project Redmi Note 12 Pro+ 5G on 26 October 2026. The browser rendered real application responses. Hardware values were not replaced with sample data.

- **Desktop:** Homeio’s browser desktop and the Advanced CPU page.
- **CPU:** six Cortex-A55 cores and two Cortex-A78 cores; eight physical and logical cores in total. Frequencies are live readings, not a benchmark.
- **Memory:** Linux-visible RAM after hardware reservations, rather than the nominal amount printed on the box.
- **GPU:** integrated ARM Mali-G68 MC4. Detection does not establish video transcoding support.

For publication, the Wi-Fi name and local address were hidden. The Jellyfin shortcut and diagnostic log area were hidden in the capture browser to keep the view clear. Jellyfin remains installed on the NAS. No CPU, GPU or memory readings were changed.

The cover in `docs/assets/redmi-nas-hero.png` is a project illustration, not a photograph of a finished enclosure. The private enclosure design is separate from this repository.

As capturas mostram o servidor real no Redmi. A capa é uma ilustração; a caixa 3D pessoal não faz parte desta publicação. Os valores visíveis nas capturas representam aquele momento, não garantias de desempenho.
