# Security and private data

Do not expose the Homeio, Jellyfin or SSH ports directly to the public internet as part of this experiment. Remote access is a separate feature and has not been configured by this repository.

Use a fresh administrator account, password and SSH keys for every installation. There are no distributed default credentials. Keep vendor firmware, Android backups, configured root filesystems, SSH private keys, Wi-Fi settings, `.env` files, cookies and database dumps out of issues and pull requests.

For a sensitive issue, do not post exploitation details or secrets in a public issue. Use GitHub private vulnerability reporting if enabled for this repository. Until it is enabled, report only a non-sensitive summary and request a private contact channel. Do not send passwords or private keys to the project author.
