# Contributing

Please include your exact model, original firmware, kernel revision, source revisions and a minimal reproduction. Distinguish bootloader failure, initramfs failure, userspace startup and network discovery problems. State whether a peripheral was physically tested.

Do not submit firmware blobs, complete phone images, credentials, personal backups or unredacted journals. Only share logs you have reviewed. Contributions retain their upstream licenses; original contributions use AGPL-3.0-only unless a file's upstream license requires otherwise.

Useful next steps: a reproducible clean rootfs/initramfs builder; a second-device installation test; hub+PD+disk validation; a phone-specific app catalog; modem/Bluetooth investigation; and upstreaming generic Homeio ARM reporting improvements.
